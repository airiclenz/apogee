---
title: The TUI checks for a newer release and names the upgrade command
---

Status: accepted

The interactive TUI checks for a newer release on every boot with one request to github.com, on by
default with two off switches, and names the upgrade command for the detected install channel on the
startup box's version row. There is no silent auto-update, `apogee update` replaces only a
release-archive install, and the network code stays outside the engine. Read `adr-0097-context`,
`adr-0097-decision`, then `adr-0097-consequences`.
