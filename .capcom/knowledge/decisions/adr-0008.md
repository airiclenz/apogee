---
title: Tools are stateless across Turns; external effects are non-forkable
---

Status: accepted

> Note (2026-10-03): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

Tools hold nothing live across Turns: their only durable side effect is filesystem writes and
`terminal` and `python_exec` stay one-shot, so a forked or resumed run inherits files and serialized
state, never a handle. MCP and network calls are non-forkable external effects the bench stubs; a
Console (ADR 0059) is the one deliberate exception. Read `adr-0008-context`, `adr-0008-decision`,
then `adr-0008-consequences`.
