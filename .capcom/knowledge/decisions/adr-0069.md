With `sub-agents-choice: model` the top-level model picks a seat per delegation (the session's
server or the Sub-agent server) through an optional `run_on`, guided by per-entry `description:`
lines; an absent `run_on` keeps the root key's rule. ADR 0039's 2026-09-20 note superseded part of
decision 6; the rest holds. Read `adr-0069-context`, `adr-0069-decision`, `adr-0069-rejected`, then
`adr-0069-consequences`.
