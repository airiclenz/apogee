---
title: Every MCP server has its own connection lifecycle
refs: [cmd/apogee/wire_mcp.go]
---

Status: accepted
Supersedes: ADR 0037 decisions 1, 7 and 8 for MCP servers only (recorded on that record as `adr-0037-amend-1107`)

Every MCP server has its own connection. A settings save touches only the servers it changes. It
dials an added or changed server off the Update loop. It closes a removed or newly denied server on
the keystroke, and that server's tools are refused at once. A finished dial joins the tool registry
at the next idle point, in one rebuild with every other finished dial. A failed re-dial keeps that
server's old session serving, and a broken server never blocks the healthy ones. The outcome reaches
the user as a transcript note per server. Startup stays all-or-nothing and fatal. Read
`adr-0109-context`, `adr-0109-decision`, `adr-0109-rejected`, `adr-0109-consequences`.
