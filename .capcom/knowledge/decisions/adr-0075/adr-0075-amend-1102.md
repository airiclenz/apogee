One addition within `v:2` under decision 10. A kind a reader does not know is one it ignores, so it does not bump the version.

**A twenty-sixth kind, `upstream_switched`.** Decision 4's list gains `upstream_switched`, written for `domain.UpstreamSwitchedEvent`: a seat has fallen over from its server to a fallback named in that entry's `fallback:` list (ADR 0105). Its `data` carries the server and model it left, the server and model it moved to, the fault that triggered it, the time waited in the grace window, and `seat`: `"session"` for the session's own Upstream (whoever on it faulted, the parent or an unrouted child) or `"sub-agents"` for a routed Sub-agents seat. One line is written per seat that moves, whichever agent on it triggered. The vocabulary is twenty-six kinds, twenty-four Event variants plus the two frames, with the new kind placed before the frames in `Kinds()`. This supersedes decision 4's "twenty-five" by amendment, not by rewrite.
