> Note (2026-10-02): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

A server switch unbinds the model and the new server's first beat completes it through the same
rebind as startup; the pickers are UI over the prepared layers and the per-server Monitor is swapped
whole. ADR 0036 made the switch the startup choice, superseding decision 5's session scope, and ADR
0076 A9 retired decision 3's validated Mechanism set. Read `adr-0028-context`, `adr-0028-decision`,
`adr-0028-rejected`, `adr-0028-consequences`, then `adr-0028-amend-0813`.
