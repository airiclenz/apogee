---
title: Project config grants are live only by adoption
---

Status: accepted
Amends: ADR 0076 (decision D10 and amendment A2 — this ADR is the stage-2b grill A2 deferred to; it closes A2's gaps (a)–(d) for the keys it admits), ADR 0012 (the project layer may only tighten — except an **Allow rule**, which is a grant the user made and is live only by **Adoption**), ADR 0032 (the workspace skill anchor becomes the **Project root**), ADR 0041 (the watcher covers two files: the global config and the **Project config**)

A project's committable `<Project root>/.apogee/config.yaml` may hold settings and allow rules, but
a granting entry is inert until the user adopts it, adoption being recorded outside the repo and
pinned to the entry's exact content. Keys are global-only by default, and precedence runs default <
global < project < env < flag. Read `adr-0096-context`, `adr-0096-decision`, `adr-0096-rejected`,
`adr-0096-consequences`, then `adr-0096-amend-1017`.
