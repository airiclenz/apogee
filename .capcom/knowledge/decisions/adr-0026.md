---
title: Workspace context files are discovered, session-scoped prompt DATA
---

Status: accepted

> Note (2026-10-02): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

Workspace context files are discovered by name, read verbatim as prompt data that never meets the
template engine, and read only at construction and at session boundaries, with sub-agents inheriting
the parent's bytes. A skip is silent, loud or fatal by whose mistake it is, and oversize is
advisory, never a cap. Read `adr-0026-context`, `adr-0026-decision`, `adr-0026-rejected`,
`adr-0026-consequences`, then `adr-0026-addendum-0826` and `adr-0026-addendum-0922`.
