> Note (2026-10-03): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

Delegations route to one sub-agent server carrying its own posture, a second heartbeat monitor
latches that server's facts engine-side as the Delegation target, and an unusable target falls back
to the parent, loudly. ADR 0066 superseded decisions 1-2 (the flag, flagged-only posture), ADR 0076
the `mechanisms:` key; the latch and the fallback hold. Read `adr-0045-context`,
`adr-0045-decision`, `adr-0045-rejected`, `adr-0045-deferred`, then `adr-0045-consequences`.
