> Note (2026-10-03): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

`apogee probe` is two halves: the bare command and `probe host` are a free, offline host report,
while `probe model` is an explicit act that spends live model calls on a capability battery and a
fuzzy fingerprint and persists the result. ADR 0076 A9 deleted §4's Validated-set promotion; the
rest still holds. Read `adr-0021-context`, `adr-0021-decision`, `adr-0021-rejected`,
`adr-0021-consequences`, then `adr-0021-amend-0722`.
