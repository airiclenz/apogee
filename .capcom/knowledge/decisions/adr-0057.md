---
title: The tool roster is a third Model-profile axis, resolved axis-wise
---

Status: accepted

> Note (2026-10-02): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

The tool roster is a third Model-profile axis of `disabled:`/`enabled:` deltas against the default
roster, ranked profile over global `tools.enabled:` over a build-level default-off; profile
resolution becomes axis-wise for all three axes, amending ADR 0044 decision 4. Read
`adr-0057-context`, `adr-0057-decision`, `adr-0057-bounds`, `adr-0057-rejected`, then
`adr-0057-consequences`.
