---
title: Endpoint `.local` names resolve over mDNS in-process
---

Status: accepted

> Note (2026-10-03): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

When the system resolver fails on an endpoint's `.local` name, apogee resolves it in-process with
one IPv4-multicast mDNS query, with no cgo and no helper program, in one shared transport's dialer;
a name neither answers is reported as unresolved. Read `adr-0091-context`, `adr-0091-decision`,
`adr-0091-rejected`, then `adr-0091-consequences`.
