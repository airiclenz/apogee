---
title: Undo is a per-Exchange snapshot pair in a session-owned git object database
---

Status: accepted

Undo is a pair of tree snapshots per Exchange in a git object database the session owns outside the
workspace, indexed by a persisted `journal.json`; revert is diff-scoped, `/redo` exists, git absent
is supported, and what git's add pipeline refuses stays with the funnel pre-image. Read
`adr-0074-context`, `adr-0074-decision`, then `adr-0074-consequences`.
