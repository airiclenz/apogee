Every popup list embeds one `listSurface` that owns the highlight, the filter and the shared key
contract, answers each key with a verdict and decides nothing about what a key means; a pane's own
code is its rows, its accept and its wording. Read `adr-0053-context`, `adr-0053-decision`,
`adr-0053-amend-0820`, `adr-0053-consequences`, then `adr-0053-amend-1014`.
