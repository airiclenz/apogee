Status: accepted; the restated "a cancel still rolls the whole Turn back" (ADR 0013 D5) superseded by ADR 0088

> Note (2026-10-03): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

A sub-agent run is addressed by its spawn call-ID through an engine-side mailbox drained between the
child's Steps; delivery is observable, a steered child's result says so, and the run view is a
transcript-slot takeover. ADR 0088 superseded the restated whole-Turn cancel rollback; the rest
holds. Read `adr-0063-context`, `adr-0063-decision`, `adr-0063-consequences`, then
`adr-0063-amend-0924`.
