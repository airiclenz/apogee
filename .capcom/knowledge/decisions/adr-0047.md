---
title: API keys resolve through a per-entry key source
---

Status: accepted

A `servers:` entry names one key source (`api-key:`, `api-key-cmd:` run with no shell, or
`api-key-env:`), resolved at first use, cached per entry, and an empty answer is a hard error. Where
a secret store can be written and read back, a plaintext key earns a consented start-up offer to
move into it. Read `adr-0047-context`, `adr-0047-decision`, `adr-0047-rejected`, then
`adr-0047-consequences`.
