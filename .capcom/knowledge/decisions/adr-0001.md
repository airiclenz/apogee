title: The agent loop is an embeddable library, driven by an external bench
---

Status: accepted; the 2026-06-25 "v1.0.0 tagged, semver begins" amendment overtaken by the 2026-07-23 restart at v0.x

> Note (2026-10-03): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

The bench (`apogee-sim`) stays out of the binary and drives the agent loop in-process by importing
apogee as a Go module, so the loop is an embeddable, steppable library: no process globals, every
state root injected through `Config`, copyable conversation state, and snapshot/resume on which the
bench composes forking. Read `adr-0001-context`, `adr-0001-decision`, `adr-0001-rejected`,
`adr-0001-consequences`, then `adr-0001-amend-0810`.
