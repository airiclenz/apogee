Color schemes are YAML palettes of optional semantic-role keys: `dark` and `light` are embedded and
a user file of the same name shadows one, `/color-scheme export` hands over an editable copy, and a
forgiving load says what it forgave in a transcript note. Schemes recolor only what apogee already
colors. Read `adr-0040-context`, `adr-0040-decision`, `adr-0040-rejected`, `adr-0040-consequences`,
then `adr-0040-amend-0808`, `adr-0040-amend-0815`, `adr-0040-amend-1105` and `adr-0040-amend-1105b`.
