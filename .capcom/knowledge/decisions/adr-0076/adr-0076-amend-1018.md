---
title: "ADR 0076 amendment of 2026-10-18: execution keys are ADR 0104"
---

Grilled on 2026-10-18 and recorded as ADR 0104, which admits the execution keys this decision
made adoption-gated. Decision 10 stays as first written; on these points ADR 0104 supersedes it:

- **MCP servers are execution keys too.** `mcp-servers:` entries in the Project config are
  adoption-gated alongside `reactions:` (ADR 0104 §1).
- **No override by key for repo entries.** A repo `reactions:` entry whose id matches a global one is
  dropped with a notice, never layered over it (§5).
- **The pin is canonical and covers named files.** It is canonical JSON of `id`, `run:`, `advise:`
  and `gate:`, plus the content of every project file the argv names (§2–§4).
- **A repo `run:` is fenced.** It runs inside the workspace exec fence when `confine-to-workspace`
  is on (§8).
