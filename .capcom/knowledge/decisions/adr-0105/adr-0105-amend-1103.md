---
title: "ADR 0105 amendment of 2026-11-03: the post-cancel landing consult joins, never walks"
---

Decided with the open bugs plan (docs/plans/2026-11-03 - 01 - open-bugs-plan.md, item 3; ratified by Airic Lenz, 2026-11-03). It amends decision 8 (the resolver owns the single-flight) and supersedes in part `adr-0105-amend-1102d`: its re-latch by "the engine's own consult joining the run that went on" on every Driver's resolver.

**The engine's post-cancel consult only ever joins.** When every routed caller of a Sub-agents seat's run is cancelled during the grace window, `adr-0105-amend-1102d` had the engine consult the resolver once more, through `Resolve` on a context stripped of the cancel, to see where the run lands. If the run ended without moving the seat in between, and so was dropped, that `Resolve` began a fresh grace window and list walk with no caller waiting on it. The engine now joins through a separate, optional interface, `FallbackLandingJoiner` (`JoinLanding(ctx, report) (FallbackAnswer, bool)`), which it type-asserts on the seat's resolver. `JoinLanding` waits for a run still in flight on the report's server and answers with it; with no run in flight it answers the zero answer and false at once, and starts no grace window, walk or landing. A run that moved the seat is never dropped, so a join after it landed reads the switch and re-latches the tree as before. `FallbackResolver` is unchanged.

**A resolver without the joiner gets no post-cancel re-latch.** An embedder's resolver that implements `Resolve` alone is never consulted after the cancel. Its landing re-latches the tree only when a routed child's own consult is answered with the switch, and until then a routed spawn may still dial the dead Sub-agent server and fall over itself. The binary's resolvers (`fallbackResolver`, and through it `seatResolver`; `sessionFallback` forwards to its current resolver without building one) all implement it, so every first-party Driver — the TUI, headless, the daemon, a Firing — keeps the at-once re-latch `adr-0045-amend-1102` asked for.
