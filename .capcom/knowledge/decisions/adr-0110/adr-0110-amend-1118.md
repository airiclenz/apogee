title: "ADR 0110 amendment of 2026-11-18: the side panel's width changes while watching a session"
refs: [docs/layout/side-panel-layout.md, internal/tui/watch.go, internal/tui/sidepanel.go]
---

**Why now.** While apogee watched another live session, a drag on the side panel's separator did
nothing, and `/panel width` was refused (issue `panel-drag-blocked-watching`, owner 2026-11-18). That
was on purpose: `adr-0110-amend-1108` (c) made the drag and `/panel width` inert in watch mode, "as
`/panel` already is there". The reason does not hold. The width is the global key
`ui.side-panel.width`, the viewer's own layout preference, and setting it writes nothing back to the
watched session (ADR 0111). The code already draws that line for a section fold, which toggles and
writes while watching, while a pin click stays refused. Watching a live session is when the
transcript and the panel need room the most, so blocking the width protects nothing.

**What this supersedes.** `adr-0110-amend-1108` (c)'s "In watch mode the drag and `/panel width` are
inert, as `/panel` already is there". The rest of (c) holds, with the default of
`adr-0110-amend-1109b` (a). It is to be read as this amendment restates it.

**(a) The width is the viewer's own, like a section fold.** While a watch is active, a press on the
grip (`adr-0110-amend-1109b` (d)) starts a resize drag exactly as outside a watch: the panel and the
transcript re-wrap live within the limits of `adr-0110-amend-1108` (a) and `adr-0110-amend-1110`,
and the release writes `ui.side-panel.width` once, only when the width changed. A double-click on
the grip resets the width to the registry default of `ui.side-panel.width` (44, per
`adr-0110-amend-1109b` (a)) and starts no drag. `/panel width <n>` and `/panel width reset` run as
outside a watch.

**(b) What stays refused.** Everything that is not the width keeps the watch refusal: a click on a
header's pin glyph, bare `/panel`, `/panel on|off|auto` and `/panel pin|unpin|hide <section>` flash
the watch refusal and write nothing. A section fold already toggled and wrote while watching, and
still does.
