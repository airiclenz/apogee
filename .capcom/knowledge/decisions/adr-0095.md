---
title: MCP OAuth tokens are persisted by apogee
---

Status: accepted; D3 and D9 amended by `adr-0095-amend-1111` (a client secret needs `issuer:` and goes only to that pinned authorization server)
Amends: ADR 0047 (decision point 8, "apogee … stores nothing itself" — it now stores MCP OAuth tokens and client registrations it minted itself, and nothing else)

apogee persists the OAuth tokens and client registrations it obtains for opted-in `streamable-http`
MCP servers, one 0600 file per server under `~/.apogee/mcp-auth/`, and no other secret. Login runs
at startup or by command, never mid-session, opens a browser only on a keypress, and the
authorization server is untrusted. Read `adr-0095-context`, `adr-0095-decision`,
`adr-0095-rejected`, `adr-0095-consequences`, then `adr-0095-amend-1111`.
