---
title: Sub-agent routing follows the `sub-agents-server` root key
---

Status: accepted
Amends: ADR 0045 (decisions 1-2)

> Note (2026-10-03): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

A root `sub-agents-server:` key names the `servers:` entry every delegation routes to, amending ADR
0045 decisions 1-2: posture is valid on any entry, the `/sub-agents-server` picker retargets a
running session without moving spawned children, and a config still carrying the retired flag gets a
migration offer. Read `adr-0066-context`, `adr-0066-decision`, `adr-0066-rejected`, then
`adr-0066-consequences`.
