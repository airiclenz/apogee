---
title: The system prompt ships an embedded default
---

Status: accepted

> Note (2026-10-02): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

The system prompt ships an embedded default, picked by a four-rung ladder (first hit wins) whose
nothing-configured case `use-default-prompt` governs; an existing `system-prompt-text:` is kept
silently. The default is config-tier, part of the Bypass floor and not a Mechanism, and a placement
rule gives guidance four homes. Read `adr-0064-context`, `adr-0064-decision`, `adr-0064-rejected`,
then `adr-0064-consequences`.
