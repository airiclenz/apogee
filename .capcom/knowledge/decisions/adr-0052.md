---
title: Diff bodies render as split diffs fed by tool-recorded Edit regions
---

Status: accepted

> Note (2026-10-03): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

Every diff-bodied block renders one body as a Split diff, or a Stacked diff where the panes cannot
breathe, decided by width at paint time; the edit tools record Edit regions at apply time as a Tool
summary variant, colour never carries a change alone, and no summary means the old rendering. Read
`adr-0052-context`, `adr-0052-decision`, `adr-0052-consequences`, `adr-0052-amend-0819`, then
`adr-0052-amend-0820`, `adr-0052-amend-0822`, `adr-0052-amend-0824` and `adr-0052-amend-1017`.
