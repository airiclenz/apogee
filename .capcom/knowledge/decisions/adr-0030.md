---
title: The TUI has one width authority, and it mirrors the painter
---

Status: accepted

The TUI has one display-width authority: a value wrapping one `ansi.Method`, riding on `theme`, that
switches from wcwidth to grapheme width at the message that moves bubbletea's renderer, so
measurement always matches what is painted; it carries the truncate, cut and wrap operations too,
not only the measure. Read `adr-0030-context`, `adr-0030-decision`, `adr-0030-rejected`, then
`adr-0030-consequences`.
