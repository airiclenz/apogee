---
title: The Exchange is a derived domain working value
---

Status: accepted

> Note (2026-10-03): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

The Exchange boundary is derived, never cached: one `CurrentExchange` derivation in
`internal/domain` finds the last user message for the engine's conversation and the request view
alike, the engine's cached start index goes, and `ExchangeView` stays unexported at the root. Read
`adr-0017-context`, `adr-0017-decision`, then `adr-0017-consequences`.
