---
title: Delegations fan out concurrently, bounded by the server's parallel-agents cap
---

Status: accepted

> Note (2026-10-03): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

Delegations the model emits in one Turn run concurrently at depth 0, loop mechanics on under Bypass,
bounded by a per-server `parallel-agents` cap: a config pin, else a `/props` discovery, else a floor
of 4 for a keyed server and 1 otherwise. The guided-decomposition trigger retired with ADR 0071 and
ADR 0076; the cap still holds. Read `adr-0039-context`, `adr-0039-decision`, `adr-0039-rejected`,
then `adr-0039-consequences`.
