title: Confinement attaches to blast radius; Auto is `confine-to-workspace`-tunable — supersedes ADR 0004
---

Status: accepted; a repo-local merge driver no longer refuses the repository — it is neutralised on every git call and only a content merge is refused, by `adr-0012-amend-1118`; path safety resolves through the one resolver `internal/realpath` and a Windows junction leaving the workspace reads as an escape, by `adr-0012-amend-1123`
Supersedes: ADR 0004

Confinement attaches to blast radius: a call runs ungated only when OS confinement or path safety
bounds it, and Auto's global `confine-to-workspace` flag (default true) fences writes, network open.
