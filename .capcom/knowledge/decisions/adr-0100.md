---
title: The global state home is one ~/.apogee dotdir on every OS
---

Status: accepted

apogee keeps all global state in a single `~/.apogee` dotdir on every OS, like `~/.aws`. It
does not use XDG base directories or `os.UserConfigDir`. A Project config layers over it and
is not a second config home.
Read `adr-0100-context`, `adr-0100-decision`, `adr-0100-rejected`, then `adr-0100-consequences`.
