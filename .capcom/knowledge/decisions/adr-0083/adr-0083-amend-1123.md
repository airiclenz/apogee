**Why now.** Part 5 reopens on "a second boot drift of the snapshot-sweep kind, where a step one
Driver runs and another silently does not". That trigger has fired. The snapshot-directory sweep
ran at TUI boot only until `6de72666` (2026-09-15) added it to headless and the daemon; then the
daemon's Firings recorded nothing into the server-stats store until `d00f0f9c` (2026-09-24) gave the
daemon the stats recorder the other Drivers already built. Both fixes were one Driver missing a
shared step, and each such step is still tested once per Driver (architecture review 2026-10-27
#7, issue `driver-preamble-copied`). The other trigger, a fourth Driver, has not fired:
`serve-http-driver` is still an open feature and is not counted here. The owner reopened part 5
on 2026-11-23, for the shared boot steps only.

**What this supersedes.** Part 5's denial, for the steps every Driver runs the same way. The rest
of part 5 stands: the verdicts that differ in kind stay with each Driver, and `hostBoot` as the
2026-09-14 review drew it (keys, skills, Bridge and the function-valued globals included) stays
denied. Part 5 is to be read with this amendment.

**(a) Taken: one Driver host for the shared steps.** One cmd-internal `driverHost`
(`cmd/apogee/driverhost.go`) opens the process-scope facilities the three Drivers (the TUI,
`apogee headless`, the daemon) each assemble by hand today: the resolved roots and the scratch
sweep, the confiner, the server-stats recorder, and the session store with its share warning and
the session and snapshot-directory sweeps. A Driver names which of these it keeps; it does not
re-spell how one is opened. One `close()` tears them down in order and returns the teardown
sentence, which the Driver reports where its notices go.

**(b) The confinement verdict stays per Driver.** The host does not decide what a confinement
sentence means. It hands each Driver a `confinementPosture` value, and the Driver judges it as
part 5 records: the TUI degrades and says so, headless refuses to run, the daemon latches the
sentence per workspace. The sentence's wording stays shared, as it already was.

**(c) The daemon's key resolver stays fenced per Firing.** The daemon has no one boot-time root,
so it keeps building its key resolver rootless and fences every resolution against the Firing's
own workspace (`KeyResolver.ResolveWithin`), as part 5's 2026-10-29 Note records. The host does
not take the resolver over.

**(d) Not taken.** The event-chain composer that would replace `firingInputs`
(`cmd/apogee/wire_firing.go`); the key resolver, skills, the Bridge and the function-valued globals
part 5's `hostBoot` also drew. The host wraps no Event sink: each Driver still composes its own
sink chain, so the journal writer of ADR 0103 decision 1 and headless's outermost `--format json`
encoder (ADR 0075 decision 9) are untouched.

**Reopens on.** A fourth Driver in `cmd/apogee` (such as `serve-http-driver`) that would carry
the verdicts or the key resolver as a fourth spelling, or a drift in a per-Driver step of the kind
this amendment fixed for the shared ones.
