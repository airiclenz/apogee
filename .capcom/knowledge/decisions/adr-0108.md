---
title: Footer git actions are the user's own act
---

Status: accepted

Clicking the footer's git segment, or running `/git`, opens a picker of six git actions on the
workspace: fetch, pull (`--ff-only`), push (never forced), sync, switch branch and rebase onto
upstream. Each one is the user's own act: it runs outside the Approver and the mode, like `/undo`,
but through the same hardened git runner as every other git apogee runs, so a repository the git
tools refuse stays refused. An action is refused while a Turn runs or a decision is pending, holds
the engine while it runs, reports its result as a transcript note, and is followed by a fresh read
of the segment's counts. Only the TUI Driver offers it. Read `adr-0108-context`,
`adr-0108-decision`, `adr-0108-rejected`, `adr-0108-consequences`.
