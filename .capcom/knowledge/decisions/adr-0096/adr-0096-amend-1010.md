---
title: "ADR 0096 amendment of 2026-10-10: the terminal matcher reads an allowlist, and `cd` strictly"
---

Decided by the owner on 2026-10-10 while plan `2026-10-10 - 00` item 9 was verified (source:
`docs/plans/archived/2026-10-10 - 00 - project-config-and-allow-rules-plan.md`, item 9 NOTES). It
sharpens decision 2's terminal sentence — "`cd` into a folder inside the workspace counts as
matched, any other `cd` asks" — which stays as the record of what was first decided.

- **An allowlist, not a denylist.** A denylist pre-scan of dangerous shell constructs failed
  verification three times, each time on a construct it did not name (quoted `${…}`, `$'`, then
  `${a[_]}` / `${PWD:_}` / `${!_}` / `${_@P}`, which bash evaluates as code). The line must now be
  built only of what the matcher reads exactly as sh and bash do: simple commands joined by `;`,
  `&&`, `||`, `|`; unquoted ASCII letters, digits and `_-./,:=+@%`; `'…'` and `"…"` of printable
  ASCII (no `$`, backtick or backslash in the double-quoted one); bare `$NAME` / `${NAME}`.
  Everything else asks — `~`, globs `*?[]`, `#`, `!`, braces, newlines, backslashes, non-ASCII
  bytes, and a word empty once its quotes are removed (`''`, `""`). So `ls *.go` and `cd ~` ask.
- **Builtins ask.** A simple command led by a shell builtin other than `cd`, `.`, `source`, `echo`,
  `pwd`, `true` and `false` asks, whatever rule names it (`test`, `[`, `printf`, `read`, `export`,
  `trap`, … — `allowAskBuiltins`), since a builtin can run code its operands only hint at.
- **`cd` is read strictly.** A `cd` is set aside as covered only in the leading run of `cd`s at the
  very start of the line, with exactly one plain relative operand (no option, `..`, `~`, `$`, `:`
  or `\`), joined to the next command by `&&` alone, and landing — symlinks resolved — in an
  existing directory inside the root. `cd .. && go test`, `go vet && cd x && go test` and
  `cd x; go test` ask. A line of nothing but `cd`s matches no rule, so an answer always names one.

Code: `internal/security/allowmatch.go` (`MatchAllowRules`, `scanMatchableShellLine`,
`allowAskBuiltins`, `allowedCdDestination`).
