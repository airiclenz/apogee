---
title: "ADR 0109 amendment of 2026-11-22: a startup-skipped repo server is an ordinary failed server"
refs: [cmd/apogee/wire_mcp.go]
---

**A startup-skipped repo server is an ordinary failed server (2026-11-22,
`docs/plans/2026-11-22 - 00 - mcp-holder-consolidation-plan.md`, item 8).** Decision 11 kept the
startup connect all-or-nothing and fatal, bar one exception it grew later: a repo server whose
adopted pin moved, or whose pinned files could not be read, is skipped rather than failing the set
(`Client.Skipped`), announced as a loud startup notice, and the config re-read cued. Until now the
MCP holder kept such a server outside its last-requested set, on a seed-only list. So the first
request that still configured it — any request at all, a `url-safety` edit or an unrelated save
included — dialled it as if it were new. That broke decision 7's rule that nothing but a change
to the server, the retry gesture or a restart re-dials a failed server.

Now the holder takes each skipped server into its last-requested set as an ordinary failed server
(decision 7): known, admitted (startup refuses a denied endpoint), with no session, and with its
last dial marked failed. The seed every view and journal opens on still reports it `failed` with
the skip's cause (`bin/wiki.sh changed since you adopted it`). From there it moves exactly as any
failed server does:

- A request that configures it unchanged never re-dials it.
- A re-adoption re-dials it. Adopting the server again moves its pin onto the files as they now are,
  which changes its config (`ServerConfig.Equal` compares the pin), so the request that carries it
  dials it.
- The `mcp-servers` row's retry gesture re-dials it, as it re-dials every server whose last dial
  failed. So does a restart.
- A request that no longer configures it says it `disconnected (removed)`, as for any known server.
  The re-read the skip cues does this when the moved server is proposed again rather than in force.

The connect itself is unchanged: still all-or-nothing and fatal for every other failure.
