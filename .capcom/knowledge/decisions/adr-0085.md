---
title: Apogee measures Upstreams and passes routing through
---

Status: accepted; the future Note's fallback pools realised by ADR 0105 (`adr-0085-amend-1102`)
Amends: ADR 0024 §6 (a configured `model` hint is trusted as configured, never replaced when the server stops listing it)

apogee measures Upstreams and passes routing hints through but never routes: a per-entry
`request-extra:` overlays the body as a JSON Merge Patch, a configured `model` is trusted as
configured, and every HTTP attempt is sampled in the provider Client, travels the event path and
persists privately in `~/.apogee/server-stats.jsonl`. Read `adr-0085-context`, `adr-0085-decision`,
`adr-0085-rejected`, `adr-0085-future`, `adr-0085-consequences`, then `adr-0085-amend-1102`.
