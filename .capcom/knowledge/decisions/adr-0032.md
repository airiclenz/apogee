---
title: The user's skill library outranks the workspace
---

Status: accepted

The user's global skill library outranks every workspace source on an id collision, the workspace
sources keep their own order among themselves, and every collision is recorded so `/skills` names
both the live copy and the shadowed one. Read `adr-0032-context`, `adr-0032-decision`,
`adr-0032-rejected`, `adr-0032-consequences`, then `adr-0032-amend-0826` and `adr-0032-amend-1010`.
