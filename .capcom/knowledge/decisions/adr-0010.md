> Note (2026-10-03): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

One hard rule shapes the packages: `internal/*` never imports the root `apogee` package.
`internal/domain` renders the domain language as Go on the standard library alone, subsystem
packages sit above it, and the root is a thin facade of aliases and wiring. The rule and the layers
hold; the Mechanism types, `NewMechanismRegistry` and `internal/mechanisms` gave way to ADR 0076.
Read `adr-0010-context`, `adr-0010-decision`, then `adr-0010-consequences`.
