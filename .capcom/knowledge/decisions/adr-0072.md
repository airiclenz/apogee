---
title: The task list is model-owned session state
---

Status: accepted
Amends: ADR 0023 (the 2026-08-25 per-session-constant bullet); ADR 0057 decision 3 is untouched

> Note (2026-10-02): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

The task list is the model's own session state: the model writes the complete list in one call, the
engine persists it with the Session and re-renders it as the last engine-owned standing block on
every request. The tool is `ReadOnly` and default-on, and a delegation starts its own empty list.
Read `adr-0072-context`, `adr-0072-decision`, `adr-0072-rejected`, then `adr-0072-consequences`.
