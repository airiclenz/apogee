---
title: "ADR 0052 amendment of 2026-10-17: the Tool summary gains an eventjson wire mirror for live watch (ADR 0103)"
---

This amendment supersedes the first bullet of amend-0824 where it says the summary value "never
reaches disk and has no wire form", and the matching "with no wire form of its own" in decision 1.
ADR 0103 decision 9 gives `domain.ToolSummary` a wire mirror owned by `internal/eventjson`, so a
live watcher can paint a tool card with its read span, match count or Edit regions while the
session runs.

What still holds:

- **The summary value never reaches the session record.** The mirror rides the Event lines and
  the Event journal only. The journal is a file on disk while its session runs and is removed when
  the session is released. The session record, the transcript codec and its `session.EditRegion`
  mirror are unchanged.
- **Nothing on a record replay path decodes the mirror.** It is decoded only for live watching.
  A resumed session still renders from the rendered tool view the codec stored (decision 5,
  ADR 0083 part 1).
- **The summary is still never sent to the model.**
