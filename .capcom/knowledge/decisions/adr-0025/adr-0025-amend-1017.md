---
title: "ADR 0025 amendment of 2026-10-17: SubAgentGroupEvent writes a sub_agent_group line (ADR 0103)"
---

This amendment supersedes one sentence of decision 2's 2026-10-05 amendment: "The event is
in-process only and writes no NDJSON line". Under ADR 0103 decision 13, `domain.SubAgentGroupEvent`
writes a `sub_agent_group` line, additively within Event lines `v:2`, so a live watcher can show
the members of a delegation wave still queued. The Driver's encoder writes the line, and the
engine stays wire-silent (ADR 0031). Everything else in that amendment stands: the event is still
emitted once before the first delegation of a group of two or more is prepared, with the same
size and run width.

ADR 0103 decision 11 adds a related line that is not an Event. Prompts and Interjections still
never enter the Event stream, so each Driver writes a `prompt` line into its Event journal itself.
