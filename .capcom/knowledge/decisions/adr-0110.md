Status: accepted (grill 2026-11-07, issue `tui-side-panel`); decisions 4, 5, 8, 9 and 14 revised 2026-11-08 before first commit (code survey for the plan: no journal on resume, no context split, the session-name rule sits above the status line)

A wide terminal gets a fixed-width column on the right, beside the transcript slot, that keeps live
session state in view: sub-agents, the task list, files changed this session and usage. It is a
glance, not a workspace: the popups and Run view stay the detail views, and a click on a section
opens its detail. Sections are pinned, auto or hidden; an auto section shows only while it is
live. The column appears or vanishes only when the terminal crosses the width gate or the user
toggles it, so live content never re-wraps the transcript. Every section folds from engine Events
alone; watch mode folds the journal, and a resumed session folds its stored record. Read `adr-0110-context`,
`adr-0110-decision`, `adr-0110-rejected`, `adr-0110-consequences`.
