Status: accepted (grill 2026-11-07, issue `tui-side-panel`); decisions 4, 5, 8, 9 and 14 revised 2026-11-08 before first commit (code survey for the plan: no journal on resume, no context split, the session-name rule sits above the status line); decisions 6 and 7 and the user-set half of "Proportional or user-set width" superseded by `adr-0110-amend-1108` (the user sets the width by dragging the separator; 36 by default); decisions 3 and 8 superseded and decision 2's MCP section designed by ADR 0111 (2026-11-08: key navigation over transcript and panel, MCP lifecycle Event), noted in blockquotes under each; decision 11 amended by `adr-0110-amend-1109` (2026-11-09: a squeezed section wears `▶` and opens into a session-only tier between pinned and auto sections)

A wide terminal gets a fixed-width column on the right, beside the transcript slot, that keeps live
session state in view: sub-agents, the task list, files changed this session and usage. It is a
glance, not a workspace: the popups and Run view stay the detail views, and a click on a section
opens its detail. Sections are pinned, auto or hidden; an auto section shows only while it is
live. The column appears or vanishes only when the terminal crosses the width gate or the user
toggles it, so live content never re-wraps the transcript. Every section folds from engine Events
alone; watch mode folds the journal, and a resumed session folds its stored record. Read `adr-0110-context`,
`adr-0110-decision`, `adr-0110-rejected`, `adr-0110-consequences`, then `adr-0110-amend-1108` and
`adr-0110-amend-1109`.
