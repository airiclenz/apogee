---
title: Terminal scripts fail fast, a confinement denial stops the call, and every session gets a scratch dir
---

Status: accepted

> Note (2026-10-03): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

POSIX terminal scripts run under a `set -e` (and `pipefail`) preamble for exit honesty, a streamed
confinement denial kills the whole confined call, every session gets a writable scratch dir inside
the box, and tracked-file mutation warnings are an always-on floor. ADR 0012 is extended, not
superseded. Read `adr-0056-context`, `adr-0056-decision`, `adr-0056-rejected`, then
`adr-0056-consequences`.
