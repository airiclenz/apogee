---
title: "ADR 0104 amendment of 2026-10-18: env display and the in-root file search"
---

Decided during the exec-keys run and in the follow-up plan of 2026-10-18. It amends decision 11:
the adoption pane shows each `env:` entry in full, as `KEY=VALUE`, not only its name; the
`env-allowlist`, `headers-env` and `client-secret-env` lines still list names. It amends decision 4
in what is searched for project files: every argv element, the program included, and every `env:`
value is searched the same way, as the whole text, each of its words, the part after a word's `=`,
and each element of a path list. Each candidate that is an existing regular file inside the Project
root is pinned by its path and the SHA-256 of its content. The re-check before every spawn, the
refusal on a mismatch and the re-proposal are unchanged. An entry adopted before the wider argv
search whose argv embeds a file (`--config=./file`) is proposed again once, since its pin now
covers that file.
