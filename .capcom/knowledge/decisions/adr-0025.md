Status: accepted; two rejected options superseded for child agents by ADR 0063; the 2026-09-14 pre-empt narrowed to a message sent now (`ctrl+g`) by its own 2026-10-05 amendment

> Note (2026-10-03): the Mechanism layer this ADR refers to was removed; ADR 0076 (Reactions) replaces it. Read the Mechanism-specific parts as historical.

A message the human sends while the model works is an Interjection: staged, then committed and
marked at the next between-Steps boundary of the running Exchange, so the model reads it mid-task; a
stop or an error holds the queue and only a natural completion flushes it. ADR 0063 overturned two
rejected options for child agents; the boundary rule still holds. Read `adr-0025-context`,
`adr-0025-decision`, `adr-0025-rejected`, then `adr-0025-consequences`.
