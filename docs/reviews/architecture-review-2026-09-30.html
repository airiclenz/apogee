Problem. Nine launch paths each wire runner, spawner, observer and asker by hand (~17 post-construction writes); the background path copies the folder-open half of Runner.Run with its own clock, and no path asks whether the folder it resumes is live.

Solution. One launch value and one builder in internal/agent; folder open stays inside internal/workflow, used by Run and the background start alike.
