Top recommendation

Start with #5 stubllm learns discovery, and take #3 the execution tools' OS is one value in the same plan.

They are one disease — package globals standing in for seams — across the two places the repo's tests most often reach past an interface: 105 global assignments in 16 Driver test files plus a guard test that exists only to police them, and 32 more in 9 tool test files that forbid t.Parallel().
