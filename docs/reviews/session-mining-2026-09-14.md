# Session Mining — apogee recorded sessions — 2026-09-14

**Scope:** every recorded apogee session under `/root/.apogee/sessions` — 130 sessions, 2026-08-13 → 2026-09-14. Parent models: deepseek-v4-flash (48 sessions, 49% of prompt tokens, 77% of tool calls), glm-5.3-flash (40), deepseek-v4-pro (3), local Qwen3.8-27B / qwen3.6-35B-A3B / gemma-4-12B (≈32), plus single-session aliases. Corpus totals (quant sweep): 2,303 parent LLM calls, 34,138 tool calls, 107.75M parent prompt tokens (82% cached where reported), 2.14M completion tokens, 131 ERROR entries, 68 `cancelled` notes in 60 sessions; 40 sessions carry `delegateUsage` — **1.49B delegate prompt tokens over 14,439 delegate calls (13.8× all parents)**. Wire STATE survives in 82/130 sessions; 48 have none.
**Mission:** find how the *harness* (not the model) can be improved as a coding agent — harness bugs, tool-surface friction, loop/delegation/skill-run control flow, token economics, model gaps a Floor guard could paper over, UX signals.
**Method:** ten sub-agents — nine bucket readers (bucket 0/1/2 = one giant `/code-audit` session each; buckets 3–8 = 20–22 sessions each) reading every session end to end from renders produced by `dump_session.py` (META / TRANSCRIPT / STATE; `--full` re-renders where needed), plus one quantitative sweep (`quant.py`, `quant2.py`) over the raw JSON. Where a reader verified a claim against source it is cited with a file:line. Source reports (ephemeral — not committed): `/tmp/claude-0/-workspace-repos-apogee/7b470b74-ea57-4d74-91a7-d17dbf337309/scratchpad/report-bucket0.md … report-bucket8.md`, `report-quant.md`, `BRIEF.md`.
**Citation convention:** `<session-suffix> [n]` is a TRANSCRIPT entry index, `STATE[n]` / `S[n]` a wire message index, exactly as the source report wrote it; full ids appear where the source used them. "Buckets" = number of readers that saw the finding independently.

## Executive Summary

The corpus is dominated by long, delegating skill runs on two OpenRouter models, and that is where the harness both spends the most and records the least: 25 of 34 skill runs did not complete (`/code-audit` 1 of 12, `/implement-plan` 0 of 5), delegates burned 13.8× the parents' tokens, roughly 1 in 11 delegations returned no usable report, and a cancel erased the wire state of the 40 cancelled sessions including the three largest. The single most repeated friction — seen by all ten readers — is confinement denying `/tmp` and the Go caches so that `go test`, `go vet`, `gh` and apogee's own `run_tests` fail until each model (and each child) rediscovers a `TMPDIR/GOTMPDIR/GOCACHE/CGO_ENABLED=0` prefix: 105 hits in 21 sessions, still 27 on 2026-09-14, followed by 295 re-prefixed commands. Close behind: paths apogee announces that its own tools refuse or prompt on (the scratch dir, in three variants — two since fixed, the read-tool refusal still live on 09-14), step-capped delegates that lose their whole output because the wrap-up Turn withdraws `write_file`, transient upstream faults that abandon a delegate with no retry, and uncapped `read_file`/`@file` inlining (a 1.02M-char CHANGELOG read, a 1.23MB `@CHANGELOG.md` costing 6.96M tokens, a 10MB ELF served as text). What worked, consistently: `ask_user` with a "(Recommended)" option, receipt-based coordination keeping coordinators at 40–90k ctx, resume-from-disk of interrupted runs, the fail-fast and confinement annotations once accurate, tree-mutation warnings, interjections landing at tool boundaries, and `/refocus` / `/archive-handoffs` finishing cleanly.
