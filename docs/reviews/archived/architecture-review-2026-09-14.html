Problem. The system prompt (with its embedded default), the shipped shape table that picks the tool-call parser and renders the tool menu for non-native models, and the roster delta are resolved only in package main; a Driver built from the root package — the bench included — runs a promptless, zero-profile agent, and inside the binary the resolution is spelled twice.

Solution. One library module — "resolve the per-model bindings for model M under these inputs → RebindSpec + notices" — reachable from the facade and used by boot, rebind, firingConfig and the bench.

  • Leverage: one interface, four Drivers
  • Locality: prompt+profile resolution in one place
  • Bench measures the product's agent
  • Two in-binary copies collapse to one
ADR 0031 invariant 4 ("no model-facing behaviour may exist only inside a binary's main()") is currently breached, not merely at risk; ADR 0033 already noted "the facade-export question re-opens" for this case. ADR 0010's thin facade is satisfied by a forwarding constructor.

Problem.
