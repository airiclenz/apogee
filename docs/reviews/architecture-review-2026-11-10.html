Problem. The panel's horizontal geometry is spread over ~15 shallow methods whose interface is as wide as their implementation. Geometry depends on navigation state (panelOverlaid reads m.cursor.inPanel(), sidepanel.go:216). 47 commits since 11-02 kept editing sidepanel.go, panelstops.go and blockcursor.go together.

Solution. Build one panelFrame per frame and carry it on pre, as withFrameSpans already does for vertical geometry. footerFit → footerLayout is the precedent in the repo.

  • Leverage: paint, click, hover and nav read one interface
  • Gate and clamp tables become pure table tests
  • No more speculative cursor copies
  • Folds the per-gesture hit-test (click, wheel, hover)

Deletion test: the 15 helpers concentrate into one constructor. Keeps ADR 0110 D6 and ADR 0111 D4 by construction.

Problem. scalarPathDepth = 2 (configwrite_scalar.go:41) refuses three-segment paths. So the side-panel block has its own 454-line splice engine, settingsHost.Write/Reset branch on config.IsSidePanelKey (wire_options.go:588, :633), SettingsHost grew two panel-only methods (tui.go:308, :319), and the folded list is computed twice. Solution. Generalise the scalar splice to any registry path. Gestures pass the whole next value, and SettingsHost shrinks back to four methods.

  • Deletes the second splice engine
  • SettingsHost interface shrinks by two
  • One writer table over depth 1–3
  • Footer keys become writable

Check during design: the sections write merges against the file ("a section the file does not name brings in the whole list"). Confirm that the session's canonical list always equals that merge. ADR 0035 D2's splice contract is unchanged.

Problem. Applying a ui.* key on screen is restated per key, per gesture and per test.   • Sweep covers every key land accepts
  • Deletes the mirrored test list
  • Pairs with #2 (the door's write half)

Problem. Six sites decide whether a server is admitted. A denied server has two representations, depending on which path denied it. Solution. The holder takes the move whole and owns the partition. settingsApplier only words the clauses.

  • Deletes 5 applier helpers
  • One representation of "denied"
  • Deny/re-dial tests need only the holder
  • No layeredConfig read in those tests

Problem. Callers must know a two-step ordering, and the holder carries a skipped list outside servers. Commit f5a2b50a touched 4 files for this one concept.   • Deletes the skipped field and its branch
  • No ordering for callers to know
  • One failed-state shape
