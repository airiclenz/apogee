Problem. The pre-first-prompt window and both advise lanes form one lifecycle, but it is driven from ~9 Agent methods, with its invariants held only in comments. Two of the last three fix(agent) commits were transitions a caller forgot.

Solution. One module owns the window, the session-started and compaction-finished lanes, and their held-for-the-Exchange runs. The Agent passes it the lifecycle events it already sees, and ordering and locking become internal.

  • Locality: a new shut site can't forget a transition
  • Tests cross the interface, not lane.waiting()
  • Boundary → swap → close sequences tested without an Agent
  • Leverage: one held ledger, three holders

The held ledger shape (pending → delivered → restored/forgotten) appears three times: background.go, and once in each lane. It folds into this module; the background manager embeds the same ledger.

ADR 0076 D6 and its 2026-10-19 / 2026-10-21 amendments: realised as written, no conflict. ADR 0018 D6 (no new Event variant): untouched.

Problem. Config seeds the Observe half of a Generation but not the Sync half, the delegation seat and target, or the undo journal. So three Drivers each hand-run one order-sensitive sequence, and the same seat-before-target bug was fixed twice on one day.

Solution. Config carries the whole construction seed, and New applies it in the one correct order before it announces. lateEngine keeps one pending Config overlay instead of ten replayed fields.

Problem. SubAgentArgs is decoded at six sites, three of which silently swallow a parse error. The background path re-runs the whole validation "in the blocking call's own words", and runDelegate takes the retained delegate before validating, which is what 32c44f71 fixed.

Solution. One module turns (call, offer) into a validated request or a refusal. prepareCall builds it once and every reader takes it from the slot. The retained delegate is taken only after validation passes.

  • Table tests: args × offer → request | refusal
  • No scripted upstream to test a refusal
  • Next argument edits one place (cf. 7cf821c9)
  • Parity test collapses to one
No ADR conflict. Refusal strings are model-facing, so they must stay byte-identical, background prefixes included.
