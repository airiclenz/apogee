## Ratified design calls

- **`apogee undo <id> confirm <generation>` — the stamp is a required third positional** (owner, 2026-09-20); bare `confirm` refuses with "preview first: …". The manual edit lands in the same commit.
- **The free `Safe{WriteFile,CopyFile,CopyFileFrom,Remove,Rename}` are deleted; `Fence` methods are the only spelling** (owner, 2026-09-20). `SafeReadFile`/`SafeOpen` stay — reads take no permit (ADR 0049 D2).
- **`Fence.Rename` keeps the no-permit rule** and `safeio.go`'s rationale verbatim: one rename is one syscall through one `os.Root` and cannot span the fence; `move`'s copy+remove fallback is the designed route, not a workaround (author — corrects the review).
- **Open/Stat do not join the fence** in this plan; `writeTarget.pin` keeps the permit-aware read-back and asks `Governs`.
- **`journalTarget` returns `(path, security.Fence)`**; an ordinary write records `WorkspaceFence(root)` so a record never claims a permit it did not run under.
- **The undo verb HOLDS the session for the verb's whole run** (not a probe-and-release); headless/daemon runs never hold, and that gap is recorded, not fixed.
- **The gitexec command-config memo stays** (documented staleness); the fix is the shell-write-view yield alone. **Superseded 2026-09-21 (owner, at `c36b76f4`, reconciling the 2026-09-20 code audit's High "`git config` command-valued key"):** the memo is re-keyed on the config's identity — item 7b. The confined writable set is the whole workspace, `.git/` included (`internal/platform/` never carves it out), so a confined `terminal` running an opaque program (`python -c "open('.git/config','a')…"`) lands a command-valued key with no argv the shell write view can see; item 7 closes the visible route only, and the probe's "attacker-authored checkout, never a config edited underneath a session" stance (gitexec.go:372-376) does not survive a model that is the editor. What does survive: `core.hooksPath` stays absent from the probe pattern (neutralised by `hardeningOptions`).
- **Strip rule** (author): an unterminated CSI/OSC is swallowed to the end of its LINE; C1 U+0080–U+009F are dropped; only `agent`'s and `skills`' clamps fold into `ClampRunes` — `capRunes`, `truncate`, `Clip`, `clipSubAgentTask`, tui `clipRunes` keep their ellipsis rules (a fold would change output).
- **`FirstLine` moves to `sanitize`** though it sheds no `title` importer.
- **`userexec` adopts the full `RunWithTeardown` contract** (clean-exit Reap included); posture stays unconfined (ADR 0073).
- **Candidate #11 is declined**; ADR 0022 §2 / 0052 §5 stand; the denial and the five *Adjudicated earlier* rulings become one ADR (owner, 2026-09-20).
