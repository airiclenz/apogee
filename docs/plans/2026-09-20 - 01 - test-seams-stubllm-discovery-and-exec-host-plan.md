## Ratified design calls

- **execHost is unexported, no `HostTools` field** (owner, 2026-09-20). A bench-facing `HostTools.Exec` is one field addable later.
- **`runOnce`/`newConfiner` are injected, not deleted** (author, on the fact-check): ADR 0033 D6 names the runner an injected seam; ~40 composition tests capture a `run.Spec` and cannot observe it from a real run.
- **`firingInputs.beat` stays** as the session's real input (`schedule.go` fills it); only the two package vars go.
- **stubllm renders `/v1/models` per wire by request headers** (`anthropic-version` present ⇒ Messages list shape), so one Script serves both wires; `/props` is served on both wires.
- **`internal/provider/discovery_test.go` stays hand-written** — the parser's own wire contract.
- **The nine other cmd/apogee function/clock globals** (`hardExit`, `interruptSignals`, `prewarmLabelWalk`, `daemonExecutable`, `daemonUserHome`, `acquireDaemonLock`, `daemonClock`, `watchSchedules`, `tuiScheduleClock`) stay; `seams_guard_test.go` therefore stays and only its hard-required list shrinks.
- **`--no-save` undo note reads `no record kept`** (author) — a new reason constant, never `reasonDisabled`'s sentence.
- **`interpreterVersion` becomes a `PythonExec` method probing through `host.run`**; `RunGitQuery` delegates to `gitexec.Run`; `DeleteFile`/`MoveFile` hold the whole `execHost` and use its `look`.
- **Exported `NewTerminal(root, secretEnv)` etc. keep their signatures** and delegate to unexported `newX(…, host)`.
