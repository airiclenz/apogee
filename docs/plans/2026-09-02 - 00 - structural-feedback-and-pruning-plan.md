NOTES (2026-09-02): a BLANK trimmed old line never scores in the window ranking; scoring blank-against-blank literally would name a run of empty lines as the "closest match".
NOTES (2026-09-02): a file with fewer lines than the old text has no full window, so its single partial window is scored over the lines it has rather than falling through to the bare sentence (edge the item's text leaves unspecified).
