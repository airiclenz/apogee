## Ratified design calls

- **Stack order = give-way order** (author, on the fact-check): the transcript-slot walk is the `framePane` index order filtered on slot; no separate `stackOrder` rank.
- **The pane table holds the funcs; `keyClaimOrder` (8 pane rows + two non-pane rungs) and a `[]framePane` pointer list keep the order** — walking the table in index order would change key and click precedence.
- **Rows resolve `paneSpecs` at call time** through closures — a package `var` that copies `paneSpecs[p].key` at declaration copies nil, since `init()` runs after var initialisers.
- **`modal bool` rides the row**; the four report `Model` fields are NOT folded into an array (134 test sites for one field per new report).
- **`UIPrefs` spells config's positive polarity** (`ShowScrollbar`, `TaskListOpen`); the renderer negates where it wants "hide"/"folded"; the zero value is never special-cased — the tui test harness seeds `{ShowScrollbar: true, TaskListOpen: true}`.
- **`cursor-shape` stays a top-level key outside `UIPrefs`**; `ui.inspector` stays inside it.
- **The registry rows CALL `UIPrefs.Set`** — a `Set` the rows do not use would be a third parser (ADR 0043's line).
- **Presence on the engine binding is pointer fields** (ADR 0046's own idiom); the value is unexported `serverBinding` with a pure `applyTo(cfg domain.Config) domain.Config` — the routed spawn has no child Agent yet, so an `Agent.apply` cannot serve it.
- **`RebindSpec`/`UpstreamSpec`/`DelegationTarget` stay public and field-identical** as thin constructors (`wire_server_test` compares `UpstreamSpec` with `!=`; the facade guard and ADR 0046 name them).
- **The routed child's `Config.EffortDialect` is mirrored** by the projection (non-wire; the live field still seeds from `d.effortDialect`) — the one deliberate divergence, named in item 11.
