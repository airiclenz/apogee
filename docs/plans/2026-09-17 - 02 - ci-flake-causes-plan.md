**Standing requirements:**
- `skills: coding-standards`
- Deviations from item text land as a dated NOTES line under the item.
- Every flake acceptance runs pinned: `go test -race -c -o "$CLAUDE_JOB_DIR/tmp/x.test" ./cmd/apogee/ && cd cmd/apogee && for i in $(seq 20); do taskset -c 0 "$CLAUDE_JOB_DIR/tmp/x.test" -test.run '^<Name>$' >/dev/null || echo FAIL $i; done` (no `$CLAUDE_JOB_DIR` → any scratch path). Never weaken an assertion to pass it.
- Bead hygiene at closeout: `bd close` each bead its item closed; the epic when all seven are closed.

**Execution host (2026-09-17 — Raspberry Pi 4, per `docs/handoffs/2026-09-17 - 00 - pi-test-suite-timing.md`):**
- Go 1.26.3 is user-local: if `go` is not found, `export PATH=$PATH:$HOME/.local/go/bin`.
- **`-race` cannot run on this host** (TSan on arm64 needs 48-bit VAs; this kernel has 39 — `FATAL: Found 39 - Supported 48`). Wherever an item or the standing pinned recipe says `go test -race …` / `go test -race -c …`, run it WITHOUT `-race` and add a NOTES line `race evidence deferred: no-TSan host` to that item. Item 10's `DATA RACE` grep is the strongest casualty: its bead closes only on race-capable evidence, so at closeout mark it `bd close` only if such evidence exists — otherwise leave the bead open with a comment and say so in the final report.
- `make test` and `scripts/test-shards.sh` hard-code `-race`, so sharded runs abort at binary startup here. For item 9, judge only the script's own output — the timings-source stderr line, and rosters read off a scratch copy of the script with ` -race` stripped, since the tracked script dies at its first race-built `-list` here — never sharded test pass/fail.
- **No landlock** (`CONFIG_SECURITY_LANDLOCK` unset; LSM list is `capability` only): `installFenceableConfiner` swaps in `fenceableHost`, so item 2's two new assertions take their log-and-skip path here and its bite check (extension fails with item 1 reverted) cannot be demonstrated — record that in NOTES; the assertions' code path is still verified compilable and the rest of the test must pass. Item 1's tests are fake-backed and unaffected.
- Load: 4 slow cores. Never run the whole suite as acceptance; keep `-run` filters exactly as written, and every `go test` invocation whose filter matches more than one test carries `-p 2 -parallel 2` — single-package multi-test acceptances included, since the default `-parallel 4` is the load the Pi handoff measured red. The serial `taskset -c 0` pinned loops are fine as written (minus `-race`).
- Known host-specific red, NOT in this plan's scope: `TestE2EHostileWrapsUnderItsOwnIndent` fails on any non-landlock host (its needle only paints when fencing is available). No plan `-run` filter matches it; if it appears in output, ignore it.

**Out of scope:** normalising CRLF in `compareGolden`; an `actions/cache` step; a goroutine-leak detector for the whole `cmd/apogee` suite; changing `DefaultTimeout`; renaming `promptTail`; confining apogee's own bookkeeping git anywhere else (`closeUndoGroup` already runs unconfined).
