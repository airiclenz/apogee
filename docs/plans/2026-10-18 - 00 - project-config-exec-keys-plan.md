# Plan: MCP servers and Reactions in the Project config, adoption-gated

**Goal:** A Project config may propose `mcp-servers:` and `reactions:` entries; each is inert until the user adopts it, and Adoption pins a canonical form of what the entry runs or where it sends data plus the content of every project file its command names (ADR 0104). Every Driver sees the same adopted set, and the adoption pane, `/settings`, `apogee project adopt` and a new `apogee mcp list` show and answer the proposals.
**Date:** 2026-10-18
**Status:** unexecuted
**sized for:** ~200k-context host
**base:** 1b25dcec
**Closes:** project-config-exec-keys

**Sources:**
- `capcom know show adr-0104-decision` (decisions §1–§12), `adr-0104-consequences`; ADR 0096 decisions 4 and 6 with `adr-0096-amend-1018`; ADR 0076 decision 10 with `adr-0076-amend-1018`
- `capcom show project-config-exec-keys`
- `docs/manual/configuration.md` §A project's own config; `docs/manual/reactions.md`; `docs/layout/user-questions-layout.md`

**Ratified design calls (owner, 2026-10-18 grill — recorded as ADR 0104; plus):**
- **`apogee mcp list`:** a new subcommand lists every configured server with its source and, for a repo server, its adoption state (owner, 2026-10-18).
- **One proposal type:** `domain.Proposal` (kind, handle, display fields, change reason, fingerprint) replaces `[]domain.AllowRule` on `ConfigHost`'s adoption methods; an Allow rule is a Proposal with no fields (writer).
- **Where pins are built:** `internal/config` builds the canonical text and file digests; `internal/adoption` stays schema-agnostic and only learns to remember the adopted text per kind and handle, which the change reason is computed from (writer).
- **Origin flag:** a repo entry carries a project-origin flag (`mcp.ServerConfig.Project`, and the same on the reaction value), set only by the config layer and read by the fences and the allow match (writer).

**Standing requirements:**
- skills: coding-standards
- Each `go test` names one package and a `-run` pattern, prefixed `GOMEMLIMIT=2GiB` (AGENTS.local.md; never a multi-package race run).
- Bubble Tea v2 names only (`tea.KeyPressMsg`, `msg.String()`).

**Out of scope:** the other execution class reserved by ADR 0076 (`mcp:` handlers, the user `shape(view)` cell); MCP servers in headless or daemon Firings (neither dials one); in-app editing of repo entries; a diff in the adoption pane.

## 6. A repo reaction's command is fenced and may name a project script

**What:** Depends on item 5. ADR 0104 §4, §8.
**Goal:** an adopted repo reaction whose program resolves inside the Project root is admitted (a global one still gets `ErrExecFromWritablePath`); a repo `run:` runs inside the workspace exec fence with the tools' secret scrub when `confine-to-workspace` is on, fails as `advise:`/`gate:` do on a host that cannot confine, and runs as a global `run:` when the fence is off.
