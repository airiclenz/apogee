# Collapsed sub-agent row: the promote-guard drops the gist, never the count — plan

**Goal:** fix the 2026-09-21 collapsed-row demotion defect: a finished delegation whose one-line
report the presenter promoted into its slot paints bare `done` (a lone run: `done · +1 more line`)
at any width where the composed `N tool calls · Nk/1.3M · <sentence>` line fails the promote-guard.
After this plan the row falls back to the same line with the engine's verdict in the gist's place, and
nothing lands in a body.

## Ratified design calls

- **Fallback drops the gist only** (owner, 2026-09-21): when the guard refuses a collapsed run's composed line, the row reads the same line with `head.tool.stat.spell()` in the gist's place (`22 tool calls · 36k/1.3M · done`, `… · stopped at its step cap`) and NOTHING lands in a body (no `+1 more line`); the report stays readable in the run view. Rejected: clipping the gist with `…`; exempting run rows from the guard.
- **The seam is gated on a paint-time flag, not on `headsRun()`** (owner, 2026-09-21): an UNFRAMED delegation (a refusal promoted into its slot; `unframedSubAgentView`, `subAgentHidesPrompt`) is a run head that must keep the ordinary demotion with its body line.

## 1. `toolView.collapsedRun` — a collapsed run's demotion keeps its composed line and grows no body

**What.** Recast at the regression check (2026-09-21). `internal/tui/toolview.go`: add the paint-time field `collapsedRun bool` beside `finished` (same rules, stated in its doc comment: set only by the painter composing a collapsed run's line, never on the wire — `toWireToolView`/`fromWireToolView` do not name it, `session.ToolView` stays untouched — not display text). In `demoted()`, after the `promotable()` early return and BEFORE the body rebuild: `if tv.collapsedRun { summary := typedSummary(tv.stat); summary.failed, summary.succeeded = tv.Summary.failed, tv.Summary.succeeded; tv.Summary = summary; tv.stat = statValue{}; return tv }`. The verdicts are copied because `typedSummary` derives `succeeded` from the whole line's text, which is no longer the bare verdict word. Extend `demoted()`'s doc comment with the collapsed-run reading (the stat IS the fallback line; the body stays zero — ADR 0063). Nothing sets the flag here; item 2 does.
**Regression guard.** the paint-time member is the VERDICT STRING, not a bool — `runVerdict string` (the engine's verdict word for the run, `head.tool.stat.spell()`; "" = not a collapsed run's reading); `demoted()` gates its run branch on `tv.runVerdict != ""` and sets `summary.succeeded = tv.Summary.succeeded || succeededSummary(tv.runVerdict)` and `summary.failed = tv.Summary.failed`; the member is listed in `sanitizeExemptToolViewMembers` (or whichever test enumerates toolView's string members) with the reason that it is a paint-time word the engine spelled, never wire or user text; item 1's unit test feeds `Summary.succeeded=false` with `runVerdict="done"` and wants `succeeded=true`, and a `runVerdict="stopped at its step cap"` case wants false. Yields to the documented call at toolview.go:108-115 / toolleader.go:343-351 (`done` is the one verdict apogee paints green — ratified call 3 of plan "2026-08-31 - 05"): the demoted collapsed row keeps that green through `succeededSummary(tv.runVerdict)`; a quoted head's `succeeded=false` alone no longer decides it.
