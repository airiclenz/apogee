# A path's real location has one resolver — plan

**Goal:** one leaf package, `internal/realpath`, answers "where does this path really live" under symlinks and Windows junctions, for existing and not-yet-created paths; every other resolver delegates to it, and no production file outside it calls `filepath.EvalSymlinks`. `security.EvalRealPath` crosses junctions, so a junction leaving the workspace reads as an escape.
**Date:** 2026-11-23
**Status:** unexecuted
**sized for:** ~200k-context host
**base:** 1f9f5369
**Closes:** real-path-five-resolvers
**Sources:** `.capcom/issues/real-path-five-resolvers.md`; `docs/reviews/architecture-review-2026-11-21.html` (#4); ADR 0020 (a Windows box root that is a reparse point is refused, never resolved through), ADR 0012 (path safety is a blast-radius bound), ADR 0096 (Project root, Adoption): `capcom know show "ADR NNNN" --with-children`; junction fixes that each patched one caller: f53e6dfc, 7ff18b95, 86a84d68, edf140b2, 74c5027e, c05956b8

**Ratified design calls** (owner, 2026-11-23):
- **Resolver home:** a new leaf `internal/realpath` importing nothing internal; `platform`, `security`, `config`, `projectroot`, `adoption`, `agent` import it.
- **Junctions:** `security.EvalRealPath` starts crossing Windows junctions; a junction escape becomes a refusal.
- **One spelling (regression check):** on Windows `ResolveLenient` always returns the volume's final name, junction or not; `Resolve` keeps its spelling rule. **Pins and allow rules (regression check):** exec pins and allow rules use the one-spelling resolver; a junction escape stops matching.
- **Re-check guards (owner, 2026-11-23):** final-name failure falls back to today's result; the Project config rule also refuses the root's final-name spelling.

**Writer's calls** (2026-11-23):
- **Missing path:** two entry points — `Resolve` (strict, errors, `fs.ErrNotExist`-classed) and `ResolveLenient` (climbs to the nearest existing ancestor, never errors).
- **ADR 0020:** the leaf exposes `IsLink`; the confiner keeps the refusal and its two sentences.
- **Sandbox roots:** a missing writable root keeps today's result per backend (lexical `Clean` for seatbelt, `exists` filter for bwrap).

**Standing requirements:**
- skills: coding-standards

**Out of scope:**

- Changing what any sandbox backend mounts or labels; the `planUnixSockets` raw-versus-canonical difference in `namespace_linux.go`; running `internal/tools`, `internal/agent` or `internal/tui` on Windows CI.
