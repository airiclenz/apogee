**Ratified design calls** (owner, 2026-09-04)
- **Profile (Balanced):** per-letter 25–45 ms; after a space 60–90; after `.` `,` `-` `!` 90–140; a 300–500 ms thinking pause at a word boundary, hard cap 2 per string. These four bands are the only `Sleep` values the generator emits.
- **Duration is not preserved:** uniform 25–45 ms means **35**, not 40, and the pauses add on top, so typed strings run longer than `40 ms × N` (task prompt ~+0.5 s before pauses). The plan pins the new totals as goldens rather than asserting the old ones.
- **Block shape:** `Set TypingSpeed 0ms` header, one `Type "c"` per character, a `Sleep` between characters only, closing `Set TypingSpeed 40ms`. No trailing `Sleep` — the tape's existing pre-`Enter` `Sleep 500ms`/`800ms` is the hover; a generator-side hover would double-count it.
- **PRNG is specified, not chosen:** MINSTD, `s = (16807 * s) % 2147483647`. `awk`'s `srand()`/`rand()` sequences differ across BSD awk, gawk and mawk and would break cross-machine byte-stability.
- **Two scripts:** `type.sh` (one string → one block) and `gen.sh` (one tape → one tape). `gen.sh` needs neither the rig nor vhs, which is what makes every item testable without `setup.sh`.
- **`--check` stays out of the record path:** fixed seed plus fixed profile makes its verdict a constant, so it could never fire per take and would only add a way to lose one.
- **Bash, not POSIX sh:** `record.sh` already uses the bash-only `${!KEY_ENV}`; `make check` does not lint shell, so `bash -n` is each item's own gate. Add no shellcheck to `Makefile`.

**Standing requirements:** `skills: coding-standards`. Any authorized deviation lands as a dated NOTES line under its item.

**Out of scope:** re-recording or rendering `graphics/demo.gif` and `graphics/demo/history/`; knob 1/2/3 *values*; VHS itself or any setting the tape does not already set; `setup.sh`, `reset.sh`, `render.sh`; `internal/`.

## 1. `type.sh` — a seeded, portable generator for one typed string — ✅ DONE (2026-09-05)

NOTES (2026-09-05): only mawk 1.3.4 is installed in this environment, so the "identical under
BSD awk, gawk and mawk" claim was verified by construction (MINSTD spelled out, no
`srand()`/`rand()`, products under 2^53) rather than by running all three.
NOTES (2026-09-05): measured at the default seed, for item 3's benefit — pooled per-letter
n=102, mean 34.451 ms; per-string totals 775 / 3382 / 1791 / 135 ms against `40 ms × N`
baselines of 720 / 2960 / 1520 / 200 ms; no Sleep outside the four bands; thinking pauses
0/0/1/0, within the cap of 2.

**What.** Add `graphics/demo/type.sh` (`bash`, `set -euo pipefail`), taking `[--seed N]` (default
`4242`) and the raw string as its **last** argument, printing the expanded block to stdout: a
`# generated by type.sh --seed N — source: "<string>"` comment, `Set TypingSpeed 0ms`, one
`Type "c"` per character with one `Sleep <n>ms` **between** consecutive characters (never after the
last), closing with `Set TypingSpeed 40ms` to restore the tape default. The gap after a character is
drawn from the band that character selects: space ⇒ 60–90; `.` `,` `-` `!` ⇒ 90–140; else ⇒ 25–45.
At a gap that follows a space, a 300–500 ms thinking pause **replaces** the space gap with
probability 1-in-8, capped at 2 per string — so the four bands stay the only values emitted.

PRNG is binding, not the implementer's choice: MINSTD `s = (16807 * s) % 2147483647`, seeded from
`--seed`, first value discarded, drawing `lo + (s % (hi - lo + 1))`. Products stay under 2^53
(16807 × 2147483646 ≈ 3.6e13), so it is exact in `awk` doubles and identical under BSD awk, gawk and
mawk. Never `srand()`/`rand()`, `$RANDOM`, `/dev/urandom`, or the clock. `APOGEE_DEMO_JITTER_MIN` /
`APOGEE_DEMO_JITTER_MAX` (ms) override the per-letter band; they exist only so item 3 can test its
own failure path and stay out of the README.

**Regression guard.** `type.sh` is the SINGLE OWNER of the four-string table (`apogee --mode auto`;
`the test suite is failing - find the bug, fix it, and prove the tests pass`; `also add a CHANGELOG

items 2 and 3 both read it from here and no copy is duplicated into `gen.sh`. Also: the script must
land mode 0755 like the four existing rig scripts (`record.sh`, `setup.sh`, `render.sh`, `reset.sh`),
