**Ratified design calls (owner, 2026-09-17):**
- **Scope:** IDEAS items 4 and 3 only; sidepanel and ←/→ navigation stay open in IDEAS.md.
- **Threshold:** type rows (the "(N)"-coalesced rows) > `ui.tools-fold-over` (int, default `5`; `0` = no umbrella is ever large).
- **Shared preference:** one `ui.tools-open` bool (default `false` — auto-fold on out of the box), silently written back on a header toggle; nil settings host = in-session only.
- **Semantics:** an umbrella is *large* when at rest (no open call) with type rows > threshold. Only large umbrellas paint `▶`/`▼` and obey `ui.tools-open`; toggling any one flips the bool for all. Small or live umbrellas keep today's header exactly (no indicator; click closes all children).
- **Folded paint:** header line only, `▶`; open large header shows `▼`; click/enter toggles the fold; child type-row state survives underneath. Supersedes tool-layout.md "never folds to one line".
- **Umbrellas:** the Tools umbrella only; Sub-Agent/Skill lists untouched.
- **Guard seam:** `git_commit` only (there is no `git_stage` tool; `stageGitPaths` re-stages tracked files and cannot add secret bytes). Pre-execute, dispatch-side I/O precompute; never a git hook (apogee runs git with `core.hooksPath=` blanked).
- **Detection:** built-in content patterns (PEM private-key block, AWS `AKIA…`, GitHub `ghp_/gho_/ghu_/ghs_/ghr_/github_pat_`, Slack `xox[abpr]-`, JWT) + path globs (`*.pem`, `*.key`, `*.p12`, `*.pfx`, `id_rsa*`, `id_ed25519*`, `id_ecdsa*`, `.env`, `.env.*` except `.env.example|sample|template`); public keys/certs not flagged; no external scanner.
- **Tier:** `TierForceApproval` in every mode; approval is the only escape (no allow-list in v1).
- **Wording:** the finding travels in the rule's Hint (the pop-up `Fix:` row and the model's deny text); the pinned `forcedApprovalReason` constant is unchanged.
- **Record:** ADR 0080 written by item 9.
