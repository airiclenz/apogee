# Upstream-stall resilience — idle timeout, re-stream budget, faulted-delegate retention

**Goal:** a delegate whose streaming call sits silent for minutes and then dies on an in-band 504 no longer loses 55 minutes of work: the engine cuts an upstream that goes silent — before its headers or mid-body — itself, re-streams a transient fault more than once with a growing hold-off, retains a faulted delegate the way a capped one is retained, and tells the parent where the child's draft output already sits (bead **apogee-60x**).
**Date:** 2026-09-20
**Status:** unexecuted
**Sized for:** ~200k-context host
**Base commit:** `182fc391`

**Sources:** `bd show apogee-60x`; `docs/handoffs/2026-09-20 - 00 - upstream-stall-resilience-and-fanout-speed.md`; ADR 0018, 0031, 0039, 0046, 0078; commit `cdd74266` (worked example of a config key end to end); `docs/manual/configuration.md` retention paragraph (~L801-826); `CONTEXT.md` P6 retention (~L775-795).

**Ratified design calls (owner, 2026-09-20 unless noted):**
- **Scope:** the per-server `request-extra:` passthrough is filed as **apogee-glh** and out of scope; apogee-2un Stage B stays parked (needs its own grill).
- **Option B shape:** a faulted delegate is retained exactly as a capped one — `foldForParent` fold + closing report into `retainedDelegates`; no raw-message retention, no snapshot.
- **Idle default:** `stream-idle-timeout` defaults to `10m`; `0` disables. Bytes of any kind (reasoning deltas, SSE comments) count as activity.
- **Re-stream budget:** `re-stream-budget` defaults to `3` per Turn; hold-off doubles from the existing 1 s base (1 s → 2 s → 4 s).
- **Slow-prefill persona:** the 10m default supersedes the 2026-08 record at CHANGELOG.md:5054-5058 that `Stream` adds no idle timeout; a local server whose prefill exceeds it sets `stream-idle-timeout: 0` or a longer value
- **Key names** (writer, 2026-09-20): `stream-idle-timeout` (duration string, `delegate-timeout` posture) and `re-stream-budget` (int; `0` = never re-stream).
- **Fault retention scope** (writer, 2026-09-20): only a child whose Run ends `Faulted` with `ctx.Err() == nil` is retained — a cancel still unwinds the whole call (subagent.go D2). No wrap-up step on a fault; the fold is the only model call, and a fold that itself fails retains with the `engineFoldUnavailableFormat` marker (the cap path's contract) and the closing report (item 5's regression guard, 2026-09-20).
